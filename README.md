## Numeric Converter
This is a C# console application to convert between binary, decimal, and hexadecimal. Choose a conversion method, input what you would like to convert, and see the results!

### Details
Currently supports conversion between:

- Decimal to Binary
- Binary to Decimal
- Decimal to Hexadecimal
- Hexadecimal to Decimal

Will add:
- Binary to Hexadecimal
- Hexadecimal to Binary
- More checks for large inputs and negative inputs 

### How to Run
1. Download ZIP
2. Unzip file
3. Open numeric-converter folder
4. Open numeric-converter.slnx on Visual Studio
5. Click the green play button at the top
6. Enjoy!
